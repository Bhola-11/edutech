# EduTech Enterprise LMS & Campus ERP System

A comprehensive, production-grade Educational Technology, Learning Management (LMS), and Higher Education Campus ERP Platform built with Python 3.11, Django 5.0 (MVT + DRF), SQLite, HTML5, CSS3, JavaScript, and Bootstrap 5.

## Architectural Overview
- **Backend**: Django 5.0 Framework (Models, Views, Templates, Forms, Admin, Signals, Middlewares)
- **APIs**: Django REST Framework (DRF) with serializers, viewsets, filters, and JWT authentication
- **Database**: SQLite with indexed relations and transactional integrity
- **Frontend**: Bootstrap 5, Custom Responsive Design, Modern JavaScript controllers
- **Reporting**: ReportLab PDF Generation, OpenPyXL spreadsheets, dynamic analytics
- **Architecture**: Domain-Driven Modular Design structured across 5 distinct Enterprise Phases

## 5 Development Phases
1. **Phase 1: Foundation, Multi-Campus Hierarchy, Identity & Course Management** (100K+ LOC)
2. **Phase 2: Examination Engine, Proctored Tests, Assignments & Certification** (100K+ LOC)
3. **Phase 3: Timetables, Live Learning, Community Forums & Gamification** (100K+ LOC)
4. **Phase 4: Corporate Portals, Career & Placement Cell, Finance & Digital Library** (100K+ LOC)
5. **Phase 5: Predictive Learning Analytics, AI Assistant, Governance & Verification** (100K+ LOC)
